# Sales Forecasting Using Machine Learning

## Project Overview

This project predicts future sales using historical Superstore sales data. The objective is to help businesses make informed decisions regarding inventory management, staffing, budgeting, and demand planning.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-Learn
* PyCharm

## Methodology

1. Data Cleaning and Preparation
2. Date Conversion and Time-Based Feature Engineering
3. Daily Sales Aggregation
4. Linear Regression Model Training
5. Model Evaluation using MAE and RMSE
6. Future Sales Forecasting for 30 Days
7. Visualization of Historical and Forecasted Sales

## Results

* MAE: 1794.17
* RMSE: 2456.22

The model successfully forecasts future sales trends and provides insights that can support business planning.

## Business Benefits

* Inventory Optimization
* Demand Forecasting
* Improved Cash Flow Planning
* Better Staffing Decisions
* Data-Driven Business Strategy
